# 🔐 Security Policy

## 📌 Supported Versions
We provide security updates only for actively maintained versions. Please ensure you are using one of the supported releases:

| Version | Supported          |
| ------- | ------------------ |
| 5.1.x   | ✅ Supported       |
| 5.0.x   | ❌ Not Supported   |
| 4.0.x   | ✅ Supported       |
| < 4.0   | ❌ Not Supported   |

---

## 🛡️ Reporting a Vulnerability
We take security seriously. If you believe you have found a vulnerability, please follow these steps:

1. **Do not disclose publicly.**  
   Please avoid creating public GitHub issues, social media posts, or forum discussions.

2. **Contact us directly.**  
   Send an email to: **haneenmaali699@gmail.com**  
   (replace with your project email or GitHub Security Advisory portal)

3. **Provide clear details.**  
   - Steps to reproduce the vulnerability  
   - Affected version(s)  
   - Expected vs actual behavior  
   - Potential impact (data loss, escalation, etc.)

4. **Response Timeline.**  
   - Acknowledgment within **72 hours**  
   - Initial assessment within **7 business days**  
   - Coordinated fixes and advisories for accepted issues

5. **Recognition.**  
   With your consent, we may credit responsible reporters in release notes or security advisories.

---

## 🔒 What to Expect
- Confirmed vulnerabilities will be patched in the next available security update.  
- Declined reports (e.g., configuration issues, non-reproducible) will include a clear explanation.  
- Security fixes are always prioritized over new features.
